## What This Tool Does

- Parse and decode Solana transaction details
- Break down instructions and their data
- Analyze account references and balances
- Extract and display all program calls
- Visualize transaction structure and flow
- Export parsed data to JSON and CSV
- Batch transaction parsing
- Support for mainnet, devnet and testnet
- Works on Windows 10 and Windows 11

Solana Transaction Parser is a professional tool for developers and analysts who need to understand Solana transaction data. It provides comprehensive decoding, instruction breakdown and account analysis. This is a fully functional application with no limitations.
